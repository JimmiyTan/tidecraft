# 客户前端演示说明

## 演示定位

客户前端演示用于在浏览器中展示 `lobster-farm` 的 Phase 07 完整业务闭环，适合现场讲解、投屏和客户体验。

页面展示：

1. 产品定位和关键价值
2. 主题输入与演示操作人
3. 内容生成、人工审核、发布准备、人工回执和归档进度
4. 5 条候选选题
5. 抖音、视频号双平台交付状态
6. 本地运行、人工确认和不自动发布的安全边界

## Windows 一键启动

在项目根目录双击：

```text
一键启动客户演示.cmd
```

脚本会启动本地服务并自动打开：

```text
http://127.0.0.1:8765
```

演示结束后，在启动窗口按 `Ctrl+C` 停止服务。

## Windows 命令启动

```powershell
.\scripts\start-customer-demo.ps1
```

不自动打开浏览器：

```powershell
.\scripts\start-customer-demo.ps1 -NoOpen
```

指定端口：

```powershell
.\scripts\start-customer-demo.ps1 -Port 8877
```

## WSL2 启动

```bash
./scripts/start-customer-demo.sh
```

## 客户演示建议顺序

1. 介绍首屏的“可审核、可交付”产品定位
2. 说明关键指标：5 条候选内容、2 个平台、100% 人工审核、0 自动发布
3. 输入客户所在行业的真实业务主题
4. 点击“开始客户演示”
5. 讲解五个状态步骤
6. 展示候选选题和双平台交付状态
7. 最后说明本地运行和人工确认安全边界

## 输入、输出、依赖和失败处理

- 输入：演示主题、演示操作人
- 输出：浏览器内的内容结果、审核状态、平台回执和归档状态
- 运行数据：仍写入 Git ignored 的 `data/`、`exports/` 和 `logs/`
- 依赖：Python 标准库和项目现有 Phase 07 模块，不需要安装前端依赖
- 失败处理：输入不合法时返回明确提示；重复点击时拒绝并发任务；服务异常时页面显示安全错误信息

## 安全边界

- 只监听 `127.0.0.1`，不向局域网或公网开放
- 固定读取 `.env.example`，不读取真实 `.env`
- 强制使用 dry-run、Feishu dry-run 和 Video mock
- 不访问浏览器个人数据
- 不调用真实飞书、视频或短视频平台发布接口
- 页面不加载外部脚本、字体、图片或统计服务
- 接口响应不返回本地文件路径、演示链接或凭据字段

## 停止和回滚

启动窗口按 `Ctrl+C` 即可停止服务。

前端演示不修改真实配置和源码状态，只生成 ignored 运行数据。如需清理演示数据，应先备份，再按任务 ID 精确处理，不要整体删除运行数据目录。
