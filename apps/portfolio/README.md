# TideCraft 单页作品集

## 定位

本目录提供 `TideCraft 潮生内容工场` 的静态单屏作品集，用于在一个手机竖屏内概览产品定位、演示界面、核心流程、关键指标和安全边界。

该页面只负责项目展示，不调用项目接口，不读取 `.env`，也不启动客户演示服务。

## 输入

- `index.html` 中的中文作品集内容
- `styles.css` 中的响应式视觉样式
- `../../assets/screenshots/customer-demo-workflow.jpg` 客户演示截图

## 输出

- 一张可直接在浏览器打开的紧凑单屏作品集
- 页面主体最大宽度为 `430px`，桌面浏览器中以手机卡片形式居中展示
- 常见手机竖屏下无需滚动即可看到完整内容
- 指向公开 GitHub 仓库的外部链接

## 依赖

- 现代浏览器
- 项目内现有客户演示截图
- 不依赖 Node.js、Python、外部字体、外部脚本或网络服务

只有点击 GitHub 链接时才需要联网。

## 使用方法

在项目根目录中双击打开：

```text
apps/portfolio/index.html
```

也可以在浏览器中将该文件拖入窗口打开。

## 失败处理

- 如果截图没有显示，请确认 `assets/screenshots/customer-demo-workflow.jpg` 仍存在，并保持当前目录结构。
- 如果 GitHub 按钮无法打开，请检查网络连接；页面其他内容仍可离线浏览。
- 如果浏览器版本较旧，毛玻璃效果可能不会显示，但不影响页面内容和布局。

## 安全边界

- 页面不读取真实配置或密钥
- 页面不发送网络请求或统计数据
- 页面不调用飞书、视频生成或短视频平台接口
- 页面不提供自动发布能力
- 页面展示的测试数字明确标注为项目结项记录

## 回滚

本作品集与现有业务模块独立。回滚时只需移除 `apps/portfolio/` 目录，不影响 `apps/customer-demo/`、核心源码、配置或运行数据。
